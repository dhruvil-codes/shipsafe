# Magic UI Terminal

Source: https://magicui.design/r/terminal.json
Documentation: https://magicui.design/docs/components/terminal
License: MIT, preserved in LICENSE.md.

The inline scan uses `Terminal` with `sequence={false}` and
`windowControls={false}`. Incoming server output is shown immediately rather than
delayed by a typing sequence. Window chrome remains optional and visible by
default for other uses. CSS maps the terminal to ShipSafe tokens and permits long,
scrollable logs. No canned scanner progress or demo output is used in the live
flow.
