# @shipsafe/shared

Canonical Zod schemas + inferred TypeScript types for ShipSafe.

Exports: `ScanManifestSchema`, `ToolResultSchema`, `NormalizedFindingSchema`,
`SecurityScoreSchema`, `ScanEventSchema` (+ `Severity`, `ScanProfile`,
`ToolStatus`, `FindingCategory`, `Confidence`, `SecurityGrade` types).

Do not change without the contract-change protocol (`docs/contracts/CHANGES.md`).
